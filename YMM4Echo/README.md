# YMM4Echo（エコー エフェクトプラグイン）

After Effects の標準エフェクト「エコー (Echo)」の挙動とパラメータを、ゆっくりMovieMaker4 (YMM4) 向けに極限まで再現した映像エフェクトプラグインです。  
映像やアイテムの現在フレームと過去のフレームを一定時間間隔で重ね合わせ、残像・光の帯・軌跡・ストローク効果を作ることができます。

---

## 主な特徴

1. **AE完全準拠の物理的軌跡＆アニメーション補間**
   - 移動速度に応じた正確なエコー間隔を物理的に再現（勝手な間隔圧縮などの独自処理を完全撤廃）。
   - 位置（DrawPoint）、拡大率（Zoom）、Z回転（Rotation）、反転（Invert）、アンカーポイント（CenterPoint）、さらに**不透明度（Opacity）**まで、サブフレーム（小数フレーム）精度で線形補間（Lerp）。
   - アイテムが回転しながら移動したり、フェードアウトや拡大率0%になっても、破綻せず自然な残像が維持されます。

2. **エコー数の大幅拡張（最大1000個対応）**
   - AEと同様に長いたなびく光の筋や濃密なトレイル表現が可能。
   - スライダーで 0〜100 個、直接入力・アニメーションで最大 **1000 個** まで設定可能。
   - 過去フレーム履歴バッファを最大 **1024 フレーム** 保持します。

3. **高速＆省メモリ設計（Direct2D階層合成 ＋ VRAM自動プール）**
   - **階層合成（バッチ＆トーナメント方式）**: 大量のエコー合成時も直列チェーンを行わず、Compositeエフェクトのマルチ入力バッチ処理（最大16入力チャンク）およびBlendエフェクトの二分木合成により、GPU負荷とエフェクトチェーン深度を激減（スタックオーバーフローやDirect2D描画クラッシュを完全防止）。
   - **スマートVRAM管理**: 必要なフレーム範囲外のビットマップをプールへ自動返却・再利用。総VRAM使用量上限（1.5GB）とメモリ不足時の自動退避・リトライ機構を搭載し、普段使いは省メモリ、大量エコー時もクラッシュせず安定動作します。

4. **画質劣化ゼロ（本体直通出力＆整数ピクセル境界キャプチャ）**
   - 現在フレーム（0番目）は元の画像入力を直接バイパス合成し、再サンプリングによるボケを完全排除。
   - 過去フレームのキャッシュも整数ピクセル境界（`Floor`/`Ceiling` + `NearestNeighbor`）で等倍コピーするため、1pxの端欠けやサブピクセル滲みが発生しません。

5. **オーバーブライト（HDR）表現対応**
   - `ColorMatrix` による強度制御を採用。開始強度や減衰に 1.0 を超える値を指定しても上限クランプされず、AE同様に強い発光・白飛び表現が可能です（Screen / Maximum / Minimum では色反転を自動防止）。

6. **インポイント境界・コマ落ち補完対応**
   - アイテム開始（インポイント）より過去のエコーはAE同様に自動で打ち切り、古いゴミ画像の混入を防ぎます。
   - プレビュー再生時のコマ落ち（欠損フレーム）も前後フレームから自動補間してエコーの歯抜けを防止します。

## 動作要件

- **ゆっくりMovieMaker4**: v4.29 以降 (.NET 10 / DirectX 11 Direct2D 描画環境)
- **OS**: Windows 10 / 11 (64bit)

## パラメーター一覧

全パラメーターがキーフレームによるアニメーション（イージング）に対応しています。

| パラメーター名 | AE対応名 | 型 / 範囲 | 初期値 | 説明 |
|---|---|---|---|---|
| **エコー時間(秒)** | エコー時間（秒） | 秒 (-10 〜 10) | `-0.033` | エコー同士の時間間隔（秒）。負の値で過去のフレーム、正の値で未来のフレーム（※リアルタイム処理のため正の値も過去側として処理されます）。 |
| **エコーの数** | エコーの数 | 個 (0 〜 1000) | `1` | 重ね合わせるエコーの枚数。UIスライダーは100まで、数値直接入力で1000まで指定可能です。 |
| **開始強度** | 開始強度 | 数値 (0 〜 10) | `1.00` | 現在フレームの不透明度（強度）。1.0超で発光・オーバーブライトになります。 |
| **減衰** | 減衰 | 数値 (0 〜 10) | `1.00` | 直前のエコーに対する次のエコーの不透明度比率。1.0で減衰なし（等倍）。$k$番目の強度は $\text{開始強度} \times \text{減衰}^k$ となります。 |
| **エコー演算子** | エコー演算子 | ドロップダウン | 後方にコンポジット | エコーを組み合わせるブレンド方式（下表）。 |

※初期値は Adobe After Effects のエコーエフェクトの標準デフォルト値と完全に一致しています。

### エコー演算子のブレンド方式

| 演算子 | 実装方式 | AEでの挙動・視覚効果 |
|---|---|---|
| **追加 (Add)** | `CompositeMode.Plus` | 強度を乗算した各エコーを単純加算合成。光が集まる部分が白飛びし、まばゆい発光感が出ます。 |
| **最大 (Maximum)** | `BlendMode.Lighten` | 各エコーの最大輝度ピクセルを採用。背景が明るい部分を残しつつエコーが重なります。 |
| **最小 (Minimum)** | `BlendMode.Darken` | 各エコーの最小輝度ピクセルを採用。暗いピクセルが優先して残ります。 |
| **スクリーン (Screen)** | `BlendMode.Screen` | 各エコーをスクリーン合成。白飛びを起こしにくく、自然に明るく重なる光の表現になります。 |
| **後方にコンポジット (Composite in Back)** | `CompositeMode.SourceOver` (反転順) | **【AE標準】** 現在フレームが最前面、過去のエコーほど奥（背後）に重なります。動く物体の後ろに自然な軌跡が残る最もポピュラーな残像です。 |
| **前方にコンポジット (Composite in Front)** | `CompositeMode.SourceOver` (正順) | 現在フレームが最背面、古いエコーほど手前に重なります。残像が手前を覆い隠す演出になります。 |
| **ブレンド (Blend)** | 算術平均 ＋ `Plus` | 全エコーの強度を枚数で除算（算術平均）して合成。全体の不透明度が維持され、透き通るような残像になります。 |

## ビルド方法（開発者向け）

1. リポジトリ直下の `Directory.Build.props` を開き、ご使用のYMM4インストールフォルダのパスを指定します。
   ```xml
   <Project>
     <PropertyGroup>
       <YMM4Dir>C:\YMM4</YMM4Dir>
     </PropertyGroup>
   </Project>
   ```
2. Visual Studio 2022（.NET 10 SDK 対応）で `YMM4Echo.sln` を開いてビルドするか、ターミナルから以下のコマンドを実行します：
   ```bash
   dotnet build YMM4Echo\YMM4Echo.csproj -c Release
   ```
3. ビルドに成功すると、`$(YMM4Dir)\user\plugin\YMM4Echo\` へ `YMM4Echo.dll` が自動的に出力されます。

## 仕様上の留意事項

- **過去フレームのみ対応**: YMM4のエフェクトパイプラインは現在描画中のフレームのみを受け取るアーキテクチャのため、未来フレームの取得はできません。正の値（未来側）を指定した場合も過去フレームとして処理されます。
- **プレビューと動画書き出し時の動作**:
  - プレビュー時のタイムラインシーク直後は未通過の過去フレーム履歴が存在しないため、再生開始直後の数フレームはエコーが少なく見える場合があります。
  - **動画の書き出し（エンコード）時は常に先頭フレームから順にレンダリングされる**ため、指定した通りの完全なエコーが常に欠落なく出力されます。
- **3D回転について**: YMM4が2D描画情報として管理する位置・ズーム・Z軸回転・反転・アンカーポイントを履歴に記録して変形します。アイテム固有の3Dカメラ変形等は平面画像としてキャッシュされます。
